DIMENSIONS
Three Directions
Every box has three dimensions: length, width and height. Each one is a different direction. If you measure two edges that go the same way, you've measured the same thing twice.
  • Drag the box to turn it around.
  • Click 3 edges: one for each dimension. Click an edge again to un-pick it.
  • Press Check.
If it's wrong you'll be shown why, and you try again. After two more tries the answer is shown.

12 boxes, 10 points each if you pick the right 3 edges the first time. 120 points possible. Get 100 or more here (and on Mass and Volume) to unlock Density.
